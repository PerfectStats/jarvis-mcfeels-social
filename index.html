PRIVATE TOOL · ONE OWNER · MCFEELS

Owner-controlled video production and YouTube delivery.

JARVIS MCFeels Social helps its owner prepare, review and manage videos for the owner's MCFeels YouTube channel. It is not a public SaaS product and does not accept third-party accounts.

Public publishing is disabled. One controlled private upload has been verified. Public-release eligibility is unverified; scheduling changes have only been tested with simulated API responses.

What the tool does

The owner reviews a long-form master. Approval authorizes derivatives made under the owner's established presentation rules. Each derivative must pass the media supervisor's evidence-based checks; exceptions return to the owner. YouTube delivery also requires a confirmed channel, current authorization and separate execution controls.

Owner control

  • Review a video and its proposed packaging.
  • Approve the master, request changes or reject it.
  • Inspect derivative previews and supervisor findings.
  • Retain control over intended publication settings.

Private by design

  • Only the owner's MCFeels YouTube channel is in scope.
  • Authorization uses Google's OAuth flow.
  • Credentials and tokens remain on the owner's server.
  • This site has no sign-in, API connection or account actions.

YouTube API use

The current owner grant contains youtube.readonly and youtube.upload. A future owner-consented migration to youtube.force-ssl alone is prepared for changing an existing video's schedule and approved metadata. That future grant has not been obtained. No subscriber, comment, message or third-party channel management is offered.
