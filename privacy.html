Privacy Policy

Last updated: September 27, 2026. Operator and privacy contact: thejustvanilla@gmail.com. This policy describes current behavior, including the limitations below; it does not assert Google approval or completed compliance review.

1. Scope

JARVIS MCFeels Social is a private tool for the owner's MCFeels YouTube channel. It uses YouTube API Services. There are no public user accounts or unrelated third-party channel-management services. This policy covers the private YouTube integration and this public documentation site. See also the Google Privacy Policy and our Terms of Service.

2. Data accessed and why

  • Channel identity: channel ID and name, with verification and owner-confirmation records, identify the intended MCFeels destination and prevent actions against the wrong channel.
  • Authorization: OAuth access and refresh tokens, granted scopes, expiry times and refresh/verification timestamps enable the connection and authorized requests. Temporary authorization state and a browser-binding cookie protect the sign-in exchange. JARVIS does not request or store Google passwords.
  • Video delivery: the owner's selected video, title, description, tags and privacy/scheduling choices are sent to YouTube only for authorized operations. Returned video IDs, URLs where available, metadata, upload progress, processing/privacy/schedule state and timestamps are used to check results, reconcile interruptions and prevent duplicate uploads.
  • Local evidence: production approvals, supervisor checks, hashes and delivery receipts document what the owner authorized and what actually happened. Owner-created source media is separate from Google-derived records. A receipt can contain both, so Google-derived fields require their own deletion handling.

Current access is channel/video reading and authorized uploading. Existing-video scheduling, rescheduling, cancellation and approved metadata updates are implemented in an isolated, simulated environment only; they require additional owner consent and execution authorization. Public publishing is disabled. This review does not evidence active YouTube Analytics collection, access to Gmail, or subscriber/message management.

3. Use, sharing and Limited Use

Google/YouTube user data is not sold. It is not shared with third parties except as necessary to provide the owner-requested functionality with the owner's consent, protect security, or comply with law. Google receives authorization requests and the content/settings necessary for requested YouTube operations. Authorized maintenance may examine only the data needed for that work. Sanitized evidence may be supplied to Google for the owner's requested compliance review; it excludes credentials and tokens.

Google/YouTube user data is not used for advertising, data-broker services, credit decisions or training general-purpose AI models. OAuth tokens are not sent to narration or media-generation providers. Human access is restricted to the owner and specifically authorized maintenance, security or legally required handling.

JARVIS MCFeels Social's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. This use-and-transfer commitment is not a claim that the separate retention and revocation controls described below have already passed audit.

4. Token storage and security

Client credentials, access tokens and refresh tokens remain in restricted files on the owner's server, outside the static website and browser code. The store checks owner-only directory/file permissions, refuses unsafe symbolic links, and writes updates atomically under a lock. Provider communication uses HTTPS. Authorization uses state validation, browser binding, PKCE and replay protection. No application-level encryption-at-rest claim is made for this file store.

The public site contains no sign-in, credential form, application cookies, advertising, tracking scripts or embedded video. The private application uses a temporary security cookie during authorization. GitHub Pages, when used to host these static pages, processes ordinary hosting/request data under GitHub's Privacy Statement. External links are governed by the destination's policy.

5. Retention: current behavior and limits

The applicable YouTube Developer Policies require most stored API data used here to be refreshed or deleted within 30 days. Owner-requested deletion must finish promptly and within seven days; Google-side revocation also requires periodic detection and deletion within 30 days. These are required operating limits, not a representation that an automated cleanup job currently exists.

6. Request deletion

Email thejustvanilla@gmail.com with the subject JARVIS YouTube data deletion. Identify the MCFeels channel and whether you want connection data only or all stored Google/YouTube data removed. Do not send passwords, tokens or client secrets. The operator verifies the request through the existing private owner relationship and handles cleanup manually; the website does not run a deletion action.

Complete cleanup must cover connection tokens, pending authorization data, channel/API records, Google-derived receipt fields and retained copies, followed by confirmation of what was removed. A token-only disconnect is not confirmation of complete deletion. The operator must meet the deletion deadline above; the end-to-end cleanup procedure still needs validation before audit submission. Owner originals are retained unless their deletion is separately requested.

Deleting data held by JARVIS does not delete uploaded videos or other data stored by YouTube. Manage YouTube-held content separately through YouTube's own tools.

7. Revoke Google access and what happens next

Open Google Account permissions, select the JARVIS connection associated with the MCFeels authorization, and remove its access. This withdraws Google's grant. You may also email the contact above to request deletion of locally stored connection/API data.

JARVIS does not currently receive an immediate revocation notification. On a subsequent authorized operation, rejected access or failed refresh stops that operation; it does not silently reconnect. A cached connected indicator may persist until another check. Previously stored tokens and receipts are not automatically erased when Google access is revoked. Manual cleanup is therefore required. Local disconnect deletes the connection files but does not programmatically revoke Google's grant; use Google's permissions page for that action. A complete in-app revocation/deletion workflow remains an implementation readiness item.

Revocation and local deletion do not cancel a release already scheduled at YouTube. Any such release must be managed separately in YouTube Studio. The recorded test upload remains private and has no external schedule.

Material changes to data access, use or sharing must be shown to the owner before the affected functionality is used, with renewed consent where required. Questions, complaints and deletion requests: thejustvanilla@gmail.com.
